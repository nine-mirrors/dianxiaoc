## 一、启动（30 秒）

```bash
# 用托管版 Node（本机唯一的 Node，未装 pnpm，统一用 npm）
export PATH="/c/Users/21820/.workbuddy/binaries/node/versions/22.22.2-3:$PATH"

cd store-app
npm install        # 只需一次，装完即可完全离线
npm run dev        # 开发服务器，默认 http://127.0.0.1:5173
```

浏览器打开 `http://127.0.0.1:5173/`，会 **直接进到业代端今日巡店（P2）**，桌面下以 390×844 手机壳呈现。

### 其他命令

| 命令 | 用途 |
|---|---|
| `npm run dev` | 本地开发，热更新 |
| `npm run build` | 常规构建，产物在 `dist/` |
| `npm run preview` | 本地静态预览 `dist/`（**现场最稳的演示方式**） |
| `npm run build:single` | 单文件构建，产出内联一切的 `dist/index.html`（灾备方案） |

> ⚠ `build:single` 的产物要把 `dist/stores/**` 图片目录与 `index.html` **放在同一目录**下再双击打开
> （`public/` 下的图片不会内联进 HTML，这是 Vite 的机制）。推荐直接用 `npm run preview`。

## 三、录屏参数

- 分辨率 **1920×1080**，浏览器窗口建议 **1440×900**，关闭书签栏。
- 手机壳模式为桌面默认；关掉开关：`window` 宽度 ≤480px 时自动退化为全屏（真机/手机模式）。
- **想慢放解说**：右上齿轮 → 加载速度切 **2×**（AI 分析动画从 2.4s 拉到约 4.8s）。
- 齿轮里还有「骨架屏开关」与「重置演示数据」（清除经理下派任务的 localStorage 增量）。

## 四、换图方法（只换文件，不动代码）

1. 把实拍图按此命名放进 `public/stores/`：

```
public/stores/S1/cold.jpg
public/stores/S2/cold.jpg   cold_before.jpg   ← 48→80 整改前后对比
public/stores/S3/cold.jpg   ambient.jpg   stack.jpg
public/stores/S4/cold.jpg
public/stores/S5/cold.jpg
public/stores/fallback/generic-shelf.jpg   ← 通用兜底图
```

2. **若构图没变**：什么都不用改，刷新即可。
3. **若构图变了**：只改 `src/fixtures/stores.json`（图片 url）与 `src/fixtures/diagnoses.json`（标注框坐标）。
   坐标是 **0–100 的相对百分比**（`x/y/w/h`，原点左上角），与图片像素尺寸完全解耦，**不需要改任何 .vue / .ts**。
4. 缺图时会自动降级到 `fallback/generic-shelf.jpg`，再失败则显示 CSS 绘制的货架示意图 +「示意图」文案，**永不白屏**。

> 图片统一 `object-fit: cover` 且裁掉底部约 5%，避开 AI 生成图右下角的「AI生成」水印。

## 五、目录结构（四层单向依赖）

```
视图层  views/          6 个页面视图，只做布局与编排
        ↑
组件层  components/     common（9）+ business（9）+ layout（3）
        ↑
领域层  domain/         纯函数：健康分 / 风险 / 问题 / 方案 / 对话引擎 / LLM 适配器
        ↑
数据层  api/ + fixtures/ 契约层（mock|http 双实现）+ 静态数据
```

**分层铁律（务必遵守）**：

- 页面/组件 **只允许** `import { xxx } from '@/api'`，**禁止** import `@/fixtures/*` 或 `@/api/mock/*`。
- `src/api/index.ts` 的 17 个方法签名 = 将来 Express 后端的真实契约（路径/请求体/响应体一字不改）。
- 接真后端时：`.env` 改 `VITE_API_MODE=http` + `VITE_API_BASE=http://localhost:3000`，**页面代码一行不动**。

## 六、关键实现约定

| 主题 | 约定 |
|---|---|
| **`0`** 权威数字 | 预置 5 家店的健康分 / 风险瓶数 / 金额 / 推导依据 / 对话答案，**全部写死在 fixture**，前端直接展示；`domain/` 的公式只在「上传陌生照片」时调用（S2 整改前展示 48 而非公式算出的 45.5） |
| **标注坐标系** | `x/y/w/h` 为 0–100 百分比；渲染时纵向除以 `IMAGE_BOTTOM_CROP=0.95` 抵消底部水印裁切 |
| **健康分分档** | 优秀 ≥85 绿 / 良好 70–84 黄绿 / 预警 60–69 橙 / 风险 <59 红，唯一出处 `domain/constants.ts` **与** `styles/tokens.css` |
| **AI 分步动画** | 5 步 × 480ms ≈ 2.4s，请求返回与动画播完取**较晚者**再跳转 |
| **对话** | 6 组预设问答（PRD 6.4 全文逐字落地）+ 2 条兜底；`domain/llmAdapter.ts` 预留但默认关闭 |
| **零 CDN** | 字体走系统字体栈，图标全内联 SVG（`AppIcon`），图表 ECharts 按需引入，图片在 `public/`；构建产物无 `http(s)://` 外域请求 |
| **离线验收** | 断网 + Network 面板外域请求数 = 0 |
