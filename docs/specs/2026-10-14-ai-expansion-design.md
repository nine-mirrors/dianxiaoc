## 1. 视觉系统（Design System 1.2）

### 1.1 品牌色（Pantone 7481C 官方标准 + 蒙牛官网线上取色）

| 令牌 | 色值 | 职责 |
|---|---|---|
| `--brand` | `#00B451` | 品牌翠绿，主按钮/品牌/健康 |
| `--brand-deep` | `#00934A` | 按下态/深色块 |
| `--brand-bright` | `#17C964` | 渐变高光/进步 |
| `--brand-mist` | `#E8FAF0` | 浅绿底/标签 |
| `--sky` | `#2FA7E0` | 信息/低温/链接 |
| `--amber` | `#FF8A1E` | 缺货/临期提醒 |
| `--red` | `#E60012` | 风险/红灯/印章 |
| `--gold` | `#C6A15B` | 品质/报告/成就 |
| `--ai` | `#7C6CF0` | AI 生成/AI 入口（AI 专属，与人工绿区分） |
| `--teal` | `#0FB5A8` | 冷链/第二数据序列 |
| `--milk` / `--ink` | `#FBFAF5` / `#14241B` | 奶白页面底 / 墨玉文字 |

换肤策略：**保留旧令牌名、只改色值**（`--mn-green`→7481C 系、`--ai-purple`→#7C6CF0 系），14 个文件中的 27 处硬编码同步替换为令牌；禁止再新增硬编码色。

### 1.2 夜间主题

- `:root`（日）与 `[data-theme="dark"]`（夜）双套令牌；夜底色 `#0C1510`、夜卡 `#13201A`、夜线 `#24332A`、夜文 `#E8F5EC`、夜翠绿 `#2DD47E`、夜 AI 紫 `#9B8CFF`、夜金 `#D8B976`、夜警报 `#FF6A52`。
- 首次进入跟随 `prefers-color-scheme`；手动切换写 `localStorage['dxc:theme']`。
- 切换动画：View Transitions API 从开关位置圆形涟漪扩散（`clip-path: circle()`）+ 日/月图标弹性形变；旧浏览器与 `prefers-reduced-motion` 降级为 400ms 颜色过渡。
- 打印（体检报告）恒为浅色。

### 1.3 招牌加载：牛奶注入奶滴（全站唯一等待语言）

- 统一符号：1.8px 线描奶滴（绿容器白奶滴），奶白液面带波浪从底部注入、气泡上浮，**注满盖过尖顶后停留**（真实产品此刻进入/完成），不允许半空结束。
- 三规格：全屏启动（深绿品牌底）、卡片内嵌（白底绿线 120px）、按钮内（58px 圆形钮，仅奶滴无文字）。
- 取代全部 spinner/旋转圈/三点跳动/假百分比；reduced-motion 下静止为满滴+静态文案。

### 1.4 其余规范

- 字体：系统字体栈；数字 `tabular-nums`；衬线（Songti/Georgia）仅报告标题/朱印。8 级字号 12/13/14/16/18/22/28。
- 间距 4pt 栅格 4·8·12·16·20·24·32；圆角 8/14/22/999；阴影三级 + 品牌绿投影 + AI 紫投影。
- 按钮三档：44px（移动主 CTA，底部双钮等宽等高）/40px（桌面表单）/32px（表格行内）；绿=人工、紫=AI、金=品质、墨玉=导出。
- 图标统一 1.8px 圆头线描、24px 网格；空状态全部线描图标，禁用 emoji。
- 图表序列固定：翠绿→智紫→天蓝→青碧→橙→红→金；AI 预测紫虚线+角标，目标金虚线；文字 ≥11px。
- 品牌元素仅四样：绿容器白奶滴品牌标、牛奶注入 Loading、报告朱印、极简天际线细线。无奶牛纹、无厚草坡、无卡通插画。

## 2. 完整功能地图（四端 × AI × 平台）

紫=本轮新增，AI=真模型驱动（DashScope qwen3-vl-plus 视觉 + qwen 文本流式，无 key 全部确定性兜底）。

### 2.1 业代端（移动）
1. 今日线路（地图/待办/天气/进度，既有）
2. **拜访八步骤**：门头签到→陈列检查→库存盘点→竞品采集→拍照诊断→下单→复盘→离店，顶部步骤进度条
3. **GPS 签到 + 照片水印**：门头照自动叠加门店名/时间/地点水印（防作弊）
4. 真机拍照三通道（相机/相册/示例，既有）
5. AI 视觉诊断（真 qwen3-vl，既有）
6. **价签/冰柜 AI 识别**：竞品价签违规、蒙牛冰柜纯净度（被竞品占比）
7. **库存盘点 + 临期登记**：结果流入补货算法
8. 问题标注/千店千面方案/追问（既有）
9. 整改单·订货单·回执前后对比（既有）
10. 巡店记录时间线（既有）
11. **AI 智能排线**：一键优化今日拜访顺序
12. **AI 知识助手**：标准/FAQ 问答（流式）
13. **消息中心**：通知公告 + 工作沟通（见 §2.5，含实时通知）
14. **我的**：战绩/AI 使用量/日夜切换/设置（替换占位页）

### 2.2 店主端（移动）
1. 自助拍照诊断（既有）
2. AI 通用陈列识别 + 六维结果（既有）
3. **AI 智能补货模拟器**：拖覆盖天数(3–14)实时算瓶数/金额/售罄日/缺货风险 + AI 口语点评
4. 一键订货确认弹层（既有）
5. 接单实时状态（既有）
6. **我的订货单**
7. **AI 进货/陈列知识问答**
8. **体检报告**（打印/导出 PDF 样式）
9. 日夜主题与设置

### 2.3 经理端（桌面）
1. 经营看板三 Tab（既有）
2. AI 晨报（既有流式）
3. **AI 经营问答 ChatBI**：大白话问数据，前端注入区域数据底稿，答案引用真实数字+门店可点击+追问 chips
4. **单店 AI 深度画像** `/manager/store/:id`：六维雷达/8 周趋势/AI 归因流式/历次诊断时间线/明细
5. **AI 周报**：一键流式生成
6. **业代绩效排行榜**：巡店量/整改率/红灯转化红黑榜
7. **黑名单预警视图**
8. **明细/周报 CSV 导出**
9. **投屏大屏模式**：深色数据墙，隐藏操作、自动轮播
10. 通知中心

### 2.4 管理员端（桌面，全新角色 admin）
1. **运营总览**：用户数/诊断数/AI 调用量趋势
2. **账号派发**：建/停用/重置密码/分配片区（业代/店主/经理/管理员）
3. **门店黑名单库**：CRUD（违规门店/问题渠道）
4. **问题 SKU / 禁售规则库**：CRUD
5. AI 诊断命中黑名单即预警（规则匹配 + AI 摘要）
6. **知识库管理**：FAQ/陈列标准 CRUD（供 AI 问答检索）
7. **审计日志**：关键操作留痕、导出
8. 公告与演示数据重置入口

### 2.5 消息中心（四端统一，WebSocket）
统一入口「消息」（未读红点/角标），两个 Tab：
- **通知公告**：管理员发布（标题、正文、送达角色范围：业代/店主/经理/全员、置顶可选）；WebSocket 实时到达，已读/未读统计，新公告首次进入弹一次轻提示。
- **工作沟通**（非泛社交 IM，会话由业务自动生成）：
  - 经理 ↔ 业代：片区群（经理+本片区域代）+ 任务单聊（下派任务时自动建会话）
  - 业代 ↔ 店主：门店会话（围绕该店订单/整改，从订单/诊断页可直接进入）
  - 文字 + 图片（复用上传）+ 快捷话术；仿 IM 气泡（人工=品牌绿/白，**AI 紫绝不用于人工消息**）；历史消息持久化 SQLite、分页加载；断线轮询兜底；输入中态可选。
- 管理员端额外：「发布公告」编辑器 + 各公告已读率；不参与工作闲聊（管理员账号只发公告）。
- 复用既有 `/ws` 通道扩展消息事件类型（announcement/message/read），不新增实时基建。

### 2.6 平台底座（横切）
日/夜双主题+涟漪动画 · 11 色令牌 · 牛奶注入 Loading · 线描图标库 · 44px/AA · 真流式 SSE · WebSocket · JWT/限流 · CSP 安全头 · 错误边界 · 访问日志/探针 · 压测达标 · CSV 导出 · 每日重置 · HTTPS 自动续证
**新增**：全局 AI 悬浮球（上下文随页）· 语音输入（Web Speech，降级文本）· 演示导览模式（脚本高亮）· 品牌化异常页（404/断网/无权限/空结果）· 首次 3 步新手蒙层 · 下拉刷新/上拉加载 · 报告海报分享卡 · PWA（manifest/图标/可加主屏）· 启动闪屏。

### 2.6b 商业价值与演示包装（评审前增补，全部纳入）
1. **AI 价值看板**（经理 + 管理员）：本月 AI 挽回销量（¥）、避免缺货损失（瓶/¥）、整改门店平均健康分提升、AI 调用次数与采纳率；数据从既有「销量损失预估 + 整改记录 + tickets」真实派生，不造假，附计算口径 tooltip。
2. **演示开场封面 + 收尾战报**：3 秒品牌开场动画（奶滴/草原/7481C，可跳过）；演示结束「今日战报」页（巡店 N 家、红灯转黄 X、挽回 ¥、AI 调用 N 次），可投屏/截图。
3. **条码快捷盘点**（业代）：盘点页支持扫商品条码（可用输入编码兜底，无摄像头不强依赖）快速计数，计入库存盘点。

### 2.7 明确不做
离线模式、多语言、复杂审批/报销流、泛社交 IM（仅做 §2.5 业务绑定的工作沟通与公告）、真实支付。

## 3. 后端新增契约（Express，沿用 Bearer 闸门/角色校验/限流/访问日志）

- `POST /api/v1/ai/ask`（SSE）`{question, context}` → 数据底稿约束的 ChatBI
- `POST /api/v1/ai/weekly-report`（SSE）经理周报
- `POST /api/v1/ai/knowledge`（SSE）`{question, role}` 知识库问答（FAQ fixtures 检索 + LLM 润色）
- `POST /api/v1/ai/route-plan`（SSE 或 JSON）智能排线说明 + 返回排序后门店
- `GET/POST/PUT/DELETE /api/v1/admin/accounts` 账号管理（admin）
- `GET/POST/PUT/DELETE /api/v1/admin/blacklist`、`/admin/sku-rules`、`/admin/knowledge`
- `GET /api/v1/admin/audit`、`POST /api/v1/admin/reset`
- `GET /api/v1/admin/overview` 运营指标
- `POST /api/v1/visits/checkin` 门头签到+水印元数据
- `POST /api/v1/stores/:id/inventory` 盘点/临期
- `GET /api/v1/rep/leaderboard`、`/api/v1/stores/:id/profile`
- `GET /api/v1/export/*.csv` 导出（CSV 注入防护：前缀转义）
- 消息中心：`GET /api/v1/messages/conversations`、`GET /api/v1/messages/:convId?cursor=`（分页）、`POST /api/v1/messages/:convId`（文字/图片）、`POST /api/v1/messages/:convId/read`；公告 `GET /api/v1/announcements`、`POST /api/v1/admin/announcements`（admin）、已读 `POST /api/v1/announcements/:id/read`；WebSocket 事件 `announcement`/`message`/`read` 广播，断线用上述 REST 补拉
- 全部新接口无 LLM key 时走确定性兜底，演示永不中断。

## 4. 数据原则
不编造新数据集：单店画像/战绩/排行榜/盘点均从既有 44 店 fixtures、8 家富诊断、tickets 派生；黑名单/知识库/账号用可重置的 SQLite 种子数据。AI 不产出硬数字（数字由前端真实字段渲染），AI 文案全部挂角标。

## 5. 波次
- W1 地基：tokens 换肤+夜间主题+主题 store+牛奶注入组件+闪屏+PWA+favicon
- W2 后端契约 + 种子数据
- W3 经理端（ChatBI/画像/周报/排行榜/黑名单/投屏/导出）
- W4 管理员端全新
- W5 业代端（八步骤/签到水印/价签冰柜/盘点临期/排线/知识/通知/我的）
- W6 店主端（模拟器/订单/知识/报告）
- W7 横切（悬浮球/语音/导览/异常页/引导/下拉刷新/海报）
- W8 日夜双主题×四角色回归、压测、终验冻结
- 每波：先备份（git+服务器包）→代理文件互斥并行→中央集成构建→浏览器验收→reset。
